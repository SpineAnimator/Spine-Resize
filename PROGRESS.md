# Прогресс

Сайт: чёрный экран, одна кнопка Resize. Файлы не уходят с компьютера. Страница `100dvh`, без прокрутки окна.

Проверено на `recovered-spine/gunslinger.skel`, `gunslinger.json`, `symbols.spine`:

- `.skel` roundtrip factor=1: 0 отличий, 30283 байта, 70 костей, версия 4.3.26.
- Bake scale: после запекания все scale = 1, мир тот же (1585×2200). В квадрат 300: 216×300, центр 0,0. Файл снова читается.
- `.json` тот же bake, AABB совпал со `.skel`.
- `.spine` raw deflate. factor=1: распакованные байты идентичны. Масштаб: 71 кость, 7 регионов, 2336 float меша. Поворот и scale костей не трогаются.
- Если в наборе есть `.skel` или `.json`, квадрат считается по их миру и тем же множителем крошится `.spine`, atlas и png.
- Только `.spine`: рамка по локальным вершинам, в строке статуса стоит `~`. Родитель в проекте по-прежнему не найден, поэтому bake scale для `.spine` не делается.

factor=1 для .skel даёт те же байты. factor=1 для .spine возвращает исходный файл.
