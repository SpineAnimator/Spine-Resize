# Прогресс

Заметки для следующего агента, со сверенными байтами и командами: [ДЛЯ-АГЕНТОВ.md](ДЛЯ-АГЕНТОВ.md). Туда же лог ошибки Spine 4.3.26 и что из него следует. Токен в репозиторий не класть.

Сайт: чёрный экран, одна кнопка Resize. Файлы не уходят с компьютера. Страница `100dvh`, без прокрутки окна. Шапка в одну строку.

Проверено на `recovered-spine/gunslinger.skel`, `gunslinger.json`, `symbols.spine`:

- `.skel` roundtrip factor=1: 0 отличий, 30283 байта, 70 костей, версия 4.3.26.
- Bake scale: мир не сдвигается (1585×2200, drift 0). После запекания все scale = 1. В квадрат 300: множитель ×0.136. Файл снова читается.
- `.json` того же персонажа едет тем же множителем.
- `.spine` raw deflate. factor=1 возвращает исходные байты. Масштаб: 71 кость, 7 регионов, 2336 float меша. Поворот и scale костей не трогаются. Родитель в проекте не найден, поэтому bake scale внутри `.spine` не делается.
- Если в наборе есть `.skel` или `.json`, квадрат считается по их миру и тем же множителем крошится `.spine`, atlas и png.
- Только `.spine`: рамка по локальным вершинам, в строке статуса стоит `~`.

`.spine` после масштаба снова заканчивается футером редактора (`02 0b 02 0b`, длина сжатого потока). Без него Spine 4.3.26 писал «The project footer is missing». factor=1 по-прежнему отдаёт исходные байты. `.skel` roundtrip не трогался.

JSON: `animations` не выкидываются. Масштабируются translate / translatex / translatey, deform, softness у IK. Файл только с `animations` (без `bones`) больше не пропускается.

Футер `.spine` режется по магии `02 0b 02 0b`, длина сжатого потока пишется в байты 4..7. Deform `offset` в JSON не масштаб. Translate в `.spine` масштабируется только обходом заголовка `84 01 01 01 01 <count>` (109 ключей на symbols.spine). Голый `01 01` не сканируется. Rotate и scale-ключи не умножаются. `.skel` не менялся.

Проверка после правки: `.skel` factor=1 — 0 отличий, 30283 байта. JSON `cherry` и `gunslinger` на месте, 7 IK на месте, deform offset остаётся индексом. `.spine` factor=1 — те же байты. После масштаба Java `Inflater` читает поток до конца и оставляет 20 байт футера.
